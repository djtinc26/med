ТЕХНИЧЕСКОЕ ЗАДАНИЕ (ТЗ)
Часть 1: Логика, Интеграции, Скрипты и Безопасность (Script & Backend Engineer)
Наименование проекта: Официальный сайт частной медицинской клиники «Новые люди» (при поддержке партии «Новые люди»)

Регион адаптации: Республика Узбекистан (+998)

Языковые версии: Русский (RU), Узбекский / Латиница (UZ), Английский (EN)

1. Архитектура и Структура Логики
Скрипты должны обеспечивать работу следующих модулей:

Onboarding & Dynamic Age System (Система первого входа, адаптации по возрасту и настройки).

Social Benefit Engine (Модуль льгот и пошаговых гайдов по электронным направлениям QR / my.gov.uz).

Telegram Notification & Booking Core (Генератор заявок, авто-определение операторов связи Узбекистана, защита от спама).

LocalStorage & Encrypted History Manager (Безопасная локальная база данных пользователя).

AI Consult Assistant (Pollinations.ai API) (Интерактивный ИИ-консультант клиники).

Multi-language System (i18n) (Динамическое переключение 3 языков).

Security & Offline-fallback module (Защита от атак, валидация, отложенная отправка).

2. Подробная Спецификация Функционала
2.1. Система первого входа (Onboarding) и обработка возраста (0-150 лет)
Проверка визита: Скрипт проверяет наличие ключа nl_user_profile в localStorage. Если ключа нет — блокирует скролл страницы и запускает Onboarding-модалку.

Ползунок возраста (Slider 0–150):

0–17 лет (Несовершеннолетние):

Появляется дополнительное поле/триггер: «Я заполняю как родитель / законный представитель» (обязательное подтверждение галочкой или кнопкой).

В Telegram-уведомлении добавляется пометка: [Заявка от родителя/опекуна].

Если ребенку нужна помощь, автоматически активируется подсказка о льготе для детей из малоимущих семей.

18–64 лет (Стандартная категория):

Отображение стандартных коммерческих услуг клиники «Новые люди».

Опциональный выбор категории «Лицо с инвалидностью» для перехода к 100% бесплатной госпрограмме.

65+ лет (Пенсионеры):

Автоматически срабатывает скрипт подсветки 100% скидки (Бесплатное лечение).

Появляется уведомление: «Вам доступно 100% бесплатное лечение по электронному направлению с QR-кодом при поддержке партии Новые Люди!».

Сохранение: Данные (язык, возраст, статус родителя/льготника) обфусцируются (Base64/JSON) и сохраняются в localStorage.

2.2. Модуль Государственных Электронных Направлений и Льгот (100% Скидка)
Скрипт проверяет категорию пользователя и динамически подгружает в специальный интерактивный блок пошаговый гайд по получению бесплатного лечения (Всё включено):

📌 Для Пенсионеров (65+ лет)
Механика 100% бесплатно: Проведение диагностики, лечения и реабилитации без дополнительных трат на лекарства и расходные материалы.

Логика интерактивного пошагового визуализатора (Инструкция в коде):

Шаг 1. Семейный врач: Визит в поликлинику (СВП / ЦСП) по месту жительства.

Шаг 2. Узкий специалист: Направление к профильному врачу (кардиолог, невролог и др.).

Шаг 3. Электронное направление: Оформление врачебно-отборочной комиссией электронного документа с матричным штрих-кодом (QR-кодом).

Шаг 4. Выбор клиники «Новые люди»: Пациент через портал my.gov.uz выбирает клинику «Новые люди» (выбор в течение 30 дней, срок действия направления — 60 дней).

📌 Для Лиц с Инвалидностью
Обращение к семейному врачу по месту жительства.

Прохождение обследования и внесение данных в электронную систему.

Генерация электронного направления с QR-кодом.

Отслеживание статуса очереди в Личном кабинете my.gov.uz (раздел «Здравоохранение»).

Получение помощи в клинике «Новые люди».

📌 Для Детей из малоимущих семей
Визит к семейному врачу (педиатру) в районной поликлинике.

Осмотр профильного специалиста (хирург, офтальмолог и т.д.).

Решение Медико-отборочной комиссии (МОК) на выдачу электронного направления.

Выбор клиники «Новые люди» через my.gov.uz в течение 30 дней.

2.3. Форма заявки, генерация ID, автоопределение оператора Узбекистана и Telegram API
Генерация номера заявки: При клике на «Отправить» скрипт генерирует рандомный 4-значный код (формат: #XXXX, от 1000 до 9999).

Валидация телефона и автоопределение оператора (+998):

Скрипт в реальном времени анализирует введенные цифры после кода +998 XX:

90, 91 ➔ Beeline Uzbekistan (событие operator_detected: beeline)

93, 94, 50 ➔ Ucell (событие operator_detected: ucell)

97, 88, 99 ➔ Mobiuz (UMS) (событие operator_detected: mobiuz)

95, 98 ➔ Uztelecom (Uzmobile) (событие operator_detected: uztelecom)

33 ➔ Humans (событие operator_detected: humans)

Скрипт передает класс/идентификатор верстке для подстановки логотипа оператора в поле ввода.

Интеграция с Telegram Bot API:

Метод отправки: POST запрос на [https://api.telegram.org/bot](https://api.telegram.org/bot)<TOKEN>/sendMessage.

Структура отправляемого сообщения:

Plaintext
🏛 Клиника «Новые люди» — Новая Заявка № [XXXX]

👤 Имя: [Имя]
📞 Телефон: +998 (XX) XXX-XX-XX [Оператор: Ucell/Beeline и т.д.]
🎂 Возраст: [Значение] лет [Пометка: Пенсионер / Родитель / Малоимущие]
🌐 Язык клиента: [RU / UZ / EN]
🎫 Статус направления: [Госкомиссия QR / Частный прием]
📅 Дата и время: [ДД.ММ.ГГГГ — ЧЧ:ММ]
2.4. Интеграция ИИ-Консультанта (Pollinations.ai API)
Эндпоинт API: Использование открытого API Pollinations (например, [https://text.pollinations.ai/](https://text.pollinations.ai/)).

Системный промпт (System Prompt):

«Ты — виртуальный медицинский консультант клиники "Новые люди" в Узбекистане, созданной при поддержке партии "Новые люди". Твоя задача: вежливо, грамотно и точно консультировать пациентов на языке пользователя ([RU/UZ/EN]), подсказывать, как получить 100% бесплатную помощь по электронным направлениям (my.gov.uz), объяснять услуги клиники и помогать записаться на прием. Не старайся ставить диагнозы, всегда рекомендуй обращение к специалистам нашей клиники.»

Логика чата:

Сохранение истории диалога в сессии.

Индикация печати («ИИ отвечает...»).

Автоматический перевод контекста в зависимости от выбранного языка сайта.

2.5. Хранение данных (LocalStorage) и Личный кабинет / Настройки
Структура ключей в LocalStorage:

nl_settings: { language: "ru", age: 67, isParent: false }

nl_applications_history: [{ id: "4821", date: "2026-10-31", status: "Отправлено", operator: "Beeline" }]

Окно «Настройки / Мои заявки»:

Изменение языка и возраста в любой момент с мгновенной перерисовкой текста на сайте без перезагрузки страницы.

Вкладка «Мои заявки»: рендеринг списка ранее отправленных 4-значных заявок клиента из localStorage.

2.6. Безопасность и Отказоустойчивость (Maximum Security Level)
Защита от спама (Rate Limiting & Honeypot):

Блокировка повторной отправки формы на 30 секунд после успешного запроса.

Honeypot-поле: скрытое CSS-поле input type="text" name="city_check" style="display:none". Если робот заполнит его — скрипт сбрасывает отправку без уведомления бота.

Защита данных от чтения (Obfuscation):

Шифрование пользовательских данных в localStorage алгоритмом Base64 с уникальным соленым ключом клиники NL_CLINIC_2026_SECURE.

Offline-fallback (Отложенная отправка):

Если при отправке нет интернет-соединения (navigator.onLine === false), скрипт сохраняет заявку в локальную очередь nl_offline_queue.

При восстановлении сети (window.addEventListener('online')) скрипт автоматически фоново досылает заявку в Telegram.
