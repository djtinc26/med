ЧАСТЬ 3: ФРОНТЕНД И ВЕРСТКА (FRONTEND & UI DEVELOPER)
Роль фронтендера: Верстка и программирование интерфейса с точным соблюдением переданных HEX-цветов, реализация бизнес-логики, валидация, интеграция Telegram API, i18n и строгие требования к оптимизации.

1. Требования к производительности и скорости сайта (Performance Requirements)
Google PageSpeed Insights: Оценка не ниже 90+ для Mobile и 95+ для Desktop.

Время первой отрисовки (FCP): Меньше 1.2 секунд.

Time to Interactive (TTI): Меньше 2.0 секунд.

Оптимизация ресурсов:

Все шрифты (Inter/Manrope) подключаются локально в формате .woff2 с font-display: swap.

Изображения в формате .webp / .svg с обязательными атрибутами loading="lazy" (кроме HERO-блока).

Минифицированные CSS и JS файлы.

2. Реализация Цветовой Палитры в CSS (Variables)

3. Функциональные модули и Frontend-логика
3.1. Onboarding & LocalStorage Manager
Скрипт проверяет наличие ключа nl_user_data в localStorage.

Если данных нет, модалка отображается с заблокированным фоновым скроллом (overflow: hidden).

При перемещении слайдера возраста (0–150):

Динамически обновлять текст значения.

Реактивно менять активные классы и видимость подсказок (Родитель / Commercial / Льготы 65+).

Данные сохраняются в закодированном виде (Base64) при нажатии кнопки «Сохранить и продолжить».

3.3. Отправка формы в Telegram Bot API
При отправке генерировать случайный 4-значный ID (Math.floor(1000 + Math.random() * 9000)).

POST-запрос к [https://api.telegram.org/bot](https://api.telegram.org/bot)<TOKEN>/sendMessage с HTML-разметкой.

Реализовать Rate Limiting: Блокировка кнопки отправки на 30 секунд после клика с обратным отсчетом таймера.

Добавить скрытый инпут Honeypot для защиты от спам-ботов.

3.4. Виджет ИИ-чата (Pollinations.ai API)
Плавающая кнопка чата в правом нижнем углу (position: fixed; bottom: 24px; right: 24px; z-index: 999).

Реализовать асинхронный fetch к [https://text.pollinations.ai/](https://text.pollinations.ai/) с системным контекстом медицинского консультанта клиники «Новые люди».

3.5. Мультиязычность (i18n)
Хранение словарей перевода в объекте const translations = { ru: {...}, uz: {...}, en: {...} }.

Автоматическая замена текстов через DOM-атрибуты data-i18n="key" без перезагрузки всей страницы.
