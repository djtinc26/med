   - **Защита от XSS и инъекций**: строгая фильтрация управляющих символов и валидация через регулярные выражения.

   - **Honeypot-ловушки**: скрытые поля для ботов-парсеров.
   - **Заголовки безопасности в HTML**: `X-Content-Type-Options: nosniff`, `Referrer-Policy: strict-origin-when-cross-origin`.

## 🚀 Как запустить проект локально на своем компьютере

1. Распакуйте архив проекта.
2. В терминале папки проекта выполните:
   ```cmd
   npm install --legacy-peer-deps
   ```
3. Запуск сайта:
   ```cmd
   npm run dev
   ```
   Откройте в браузере: `http://localhost:3000`
4. Запуск Telegram-бота (во втором терминале):
   ```cmd
   npm run bot
   ```

## 🌐 ГАЙД: Как запустить сайт и бота 24/7 в облаке (чтобы работало при выключенном ПК)

Когда вы запускаете проект на своем компьютере, он работает только пока компьютер включен. Чтобы сайт и бот были доступны **круглосуточно 24/7/365 из любой точки мира, даже когда ваш ПК полностью выключен**, проект нужно развернуть на бесплатном или дешевом облачном сервере.

Ниже 3 простых и проверенных способа:

---

### СПОСОБ 1 (Самый простой и бесплатный): Vercel + Render

В этом варианте:
- **Веб-сайт** круглосуточно работает на **Vercel** (бесплатный глобальный CDN с максимальной скоростью и SSL).
- **Telegram-бот** круглосуточно работает на **Render** (бесплатный фоновый воркер).

#### Шаг 1. Загрузите проект на GitHub
1. Зарегистрируйтесь на [github.com](https://github.com) (если нет аккаунта).
2. Создайте новый репозиторий (например, `new-people-clinic`).
3. Загрузите файлы проекта в репозиторий через GitHub Desktop или консоль Git:
   ```bash
   git init
   git add .
   git commit -m "Initial clinic release"
   git branch -M main
   git remote add origin https://github.com/ВАШ_АККАУНТ/new-people-clinic.git
   git push -u origin main
   ```

#### Шаг 2. Разверните сайт на Vercel (1 минута)
1. Перейдите на [vercel.com](https://vercel.com) и войдите через свой GitHub.
2. Нажмите **«Add New...» -> «Project»**.
3. Выберите репозиторий `new-people-clinic`.
4. Vercel автоматически определит Vite + React.
5. Нажмите **«Deploy»**.
6. Через 40 секунд вы получите постоянный публичный адрес (например: `https://new-people-clinic.vercel.app`).
👉 **Сайт будет работать 24/7 бесплатно навсегда!**

#### Шаг 3. Запустите Telegram-бота на Render (2 минуты)
1. Перейдите на [render.com](https://render.com) и войдите через GitHub.
2. Нажмите **«New +» -> «Background Worker»** (или «Web Service»).
3. Подключите ваш репозиторий `new-people-clinic`.
4. В поле **Build Command** укажите:
   ```bash
   npm install --legacy-peer-deps
   ```
5. В поле **Start Command** укажите:
   ```bash
   npx tsx bot.ts
   ```
6. В разделе **Environment Variables** добавьте:
   - Имя: `TELEGRAM_BOT_TOKEN`
   - Значение: `9108520636:AAG7ieFMo7V07ycEtyjdXpjMM2Mt4FFVm1o`
7. Нажмите **«Create Background Worker»**.
👉 **Бот будет работать 24/7 без остановки и моментально отвечать вам в Telegram!**

### СПОСОБ 2 (Все в одном месте): Railway.app

Если вы хотите запустить и сайт, и бота в одном сервисе:
1. Зарегистрируйтесь на [railway.app](https://railway.app).
2. Нажмите **«New Project» -> «Deploy from GitHub repo»**.
3. Добавьте сервис для сайта:
   - Build: `npm run build`
   - Start: `npm run preview`
4. Добавьте второй сервис для бота:
   - Start: `npm run bot`
5. Railway дает бесплатные часы каждый месяц. Ваш сайт и бот будут доступны непрерывно.

### СПОСОБ 3 (Свой виртуальный сервер VPS за $2-3 в месяц — Максимальный контроль)

Если вы хотите развернуть проект на собственном сервере в Узбекистане, России или Европе (хостинги TimeWeb, Aeza, Hetzner, Beget):

1. Закажите минимальный VPS с операционной системой **Ubuntu 22.04 или 24.04 LTS** (1 CPU, 1–2 GB RAM).
2. Подключитесь к серверу по SSH через терминал или PuTTY:
   ```bash
   ssh root@IP_ВАШЕГО_СЕРВЕРА
   ```
3. Установите Node.js 20 и менеджер фоновых процессов PM2:
   ```bash
   curl -fsSL https://deb.nodesource.com/setup_20.x | bash -
   apt-get install -y nodejs git
   npm install -g pm2
   ```
4. Склонируйте ваш репозиторий на сервер:
   ```bash
   git clone https://github.com/ВАШ_АККАУНТ/new-people-clinic.git
   cd new-people-clinic
   npm install --legacy-peer-deps
   npm run build
   ```
5. Запустите сайт и бота через PM2 в фоновом режиме (они никогда не выключатся):
   ```bash
   # Запуск веб-сайта
   pm2 start "npm run preview -- --port 80 --host 0.0.0.0" --name "clinic-web"

   # Запуск Telegram-бота
   pm2 start "npx tsx bot.ts" --name "clinic-bot"

   # Настройка автозапуска при перезагрузке сервера
   pm2 startup
   pm2 save
   ```
6. Проверить статус работающих процессов:
   ```bash
   pm2 list
   pm2 logs clinic-bot
   ```
👉 Теперь сервер работает круглосуточно. Вы можете выключать свой компьютер, закрывать крышку ноутбука — сайт и бот клиники «Новые люди» будут непрерывно принимать пациентов и присылать заявки вам в Telegram!
